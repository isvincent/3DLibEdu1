# 🏝️ 桃園市立楊梅高級中學圖書館｜3D 數位知識島 (RWD & PWA 旗艦版)

本專案將《楊梅高中 115 學年圖書館新生利用教育說明資料》轉化為互動式 **Three.js 3D 數位知識島**。支援 **RWD 響應式網頁設計**（手機、平板、桌機自適應）與 **PWA 漸進式網路應用程式**（支援離線瀏覽、安裝至手機/電腦主畫面、LocalStorage 自動保存探索進度）。

---

## 📂 GitHub 專案目錄結構

```text
ymhs-library-3d-island/
├── index.html          # 主程式首頁（整合 Three.js 3D 雙島場景、RWD 介面、語音音效、11題計時賽與證書產出）
```

## ✨ 核心教學與技術特色

1. **雙島嶼 3D 空間映射（主島 ＋ 啟明樓藝文分島）**
   - **🏛️ 1. 圖書館環境導覽塔**：1F（辦公區、服務櫃台、期刊區、資訊檢索區、梅高特藏區、討論室、閱讀區）、2F（書庫、閱讀區）、開放時間（08:00~16:00，第8堂未上輔導課可入館自習，打掃時間禁入）。
   - **🎨 2. 啟明樓藝文分島（跨海木造吊橋連結）**：啟明樓 1F「喜閱學堂」、4F「紅土藝術空間」與學校首頁線上電子書資源。
   - **📚 3. 借閱魔法轉運站**：借書動線（1F入館➔2F找書➔16:00前1F櫃台借書）、憑學生證最多借 4 本 / 借期 2 週、到期前 1~2 日續借 2 週、逾期停權天數計算、館藏查詢 5 步驟。
   - **💳 4. 科技與特藏工坊**：自備悠遊卡（餘額 10 元以上）黑白印/影 2 元、彩色 6 元、掃描過卡免費；梅高特藏（梅岡風、畢冊、梅高青年）、1F 當月期刊、2F 漫畫限館內閱讀（過期雜誌移 2F 可外借）；家用版與公播版 DVD 規範。
   - **🛡️ 5. 秩序與 RFID 守護結界**：禁帶飲食（含礦泉水）與書包（可帶個人書籍）、禁做海報/畢冊、上課入館須帶學生證登記並由教師簽署證明、全區監控與圖書 RFID 安全系統。
   - **⚡ 6. FAQ 11 題連續計時試煉神殿**：完整收錄 Q01～Q11 常見問題（含午休留館規定與新書推薦 5 步驟），答對 8 題以上即可解鎖神殿徽章。

2. **RWD 響應式跨裝置體驗**
   - 自動偵測手機直向/橫向、平板與桌面螢幕比例，動態調整 3D 攝影機視野（FOV 與距離）。
   - 支援手機單指旋轉、雙指縮放，並具備「防誤觸拖曳判定」，避免滑動視角時誤開彈窗。
   - 底部導覽列於小螢幕自動轉為平滑橫向捲動抽屜，並支援 iOS `safe-area-inset` 安全邊距。

3. **PWA 漸進式應用與學習歷程證書**
   - 內建 `manifest.json` 與 `sw.js`，學生可點擊頂部 **「📲 安裝 APP」** 將知識島安裝至手機或平板桌面。
   - 內建 `localStorage` 自動記憶已解鎖的徽章與最高分。
   - 點擊 **「🎓 通行證」** 輸入班級、座號、姓名，即可即時繪製並下載高解析度 `.png` 學習證明卡。

## 🚀 GitHub Pages 快速部署步驟

1. 在 GitHub 建立一個新的公開儲存庫（例如：`ymhs-library-3d-island`）。
2. 將本專案所有檔案（`index.html`、`manifest.json`、`sw.js`、`README.md` 及 `icons/` 資料夾）上傳至儲存庫根目錄。
3. 進入儲存庫的 **Settings** ➔ 左側選單點選 **Pages**。
4. 在 **Build and deployment** 下方的 **Branch** 選擇 `main`（或 `master`），資料夾選擇 `/ (root)`，點擊 **Save**。
5. 等待約 1～2 分鐘，即可透過 `https://<您的GitHub帳號>.github.io/ymhs-library-3d-island/` 讓全校新生連線體驗！
